# Galeria de agentes

Templates prontos capturados na FILA (`company/FILA.md`) como ponto de
partida da entrevista do `/arvys:hire --de <template>` — nenhum agente daqui
nasce `ativo`: todo template carrega `status:` = candidato, e contratar um
deles passa pela mesma guarda anti-pasta-morta de qualquer agente novo (uso semanal
previsto, fonte de dados, cisão/demanda justificada). Contribuir com um novo
candidato é feito via PR ao repositório do plugin, seguindo o molde de
`plugin/templates/agent/AGENT.md` — decisão registrada em
`company/DECISIONS.md` (2026-08-31, "Melhoria coletiva por contribuição,
NUNCA por absorção").
